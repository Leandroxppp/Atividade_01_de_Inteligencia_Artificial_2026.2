# Lista 1 — Inteligência Artificial (2026.2)

Resolução organizada por questão para publicação no GitHub.

## Estrutura

- `Questao_1`: base ampliada para 30 exemplos e 6 atributos; construção manual de ID3, C4.5 e CART; regras e comparação.
- `Questao_2`: geração computacional de ID3, C4.5 e CART sobre a mesma base da Questão 1, com árvores e regras.
- `Questao_3`: árvore de decisão na base Breast Cancer Wisconsin + regras + Accuracy, Precision, Recall e F1-score.
- `Questao_4`: geração direta de regras com PRISM na mesma base/divisão da Questão 3 + métricas.
- `Questao_5`: shell genérico para sistemas baseados em conhecimento, com forward, backward, misto, COMO?/POR QUÊ?, editor e persistência JSON.

## Instalação

```bash
pip install -r requirements.txt
```

Cada pasta contém um `README.md` com a explicação e os comandos de execução.
